# End-to-End AI Insurance Risk Analytics

*(This template is designed to be adapted into a Medium-style blog post.)*

## 1. Executive Summary (Non-Technical)

- Who is ACIS and what is the business problem?
- What did we do with the data?
- What are the 3–5 most important insights?
- What actions do we recommend?

## 2. Data & Methodology

- Data source, time period, key fields
- High-level description of:
  - EDA
  - Hypothesis testing
  - Machine learning models
  - Model interpretability (SHAP/LIME)

## 3. Exploratory Data Analysis

- Overall portfolio metrics
- Risk and profitability by:
  - Province
  - Vehicle type
  - Gender
  - Zip code
- Key plots and what they show
- Surprising or counterintuitive findings

## 4. Hypothesis Testing Results

For each null hypothesis:

1. **Risk differences across provinces**
2. **Risk differences between zip codes**
3. **Margin differences between zip codes**
4. **Risk differences between women and men**

For each:

- Test used (chi-square, t-test, ANOVA, etc.)
- p-value and interpretation
- Business takeaway (e.g. adjust premiums for specific segments)

## 5. Predictive Modeling

- Severity model (regression)
  - Target, features, models tried
  - Performance metrics (RMSE, R²)
- Claim probability model (classification)
  - Target, features, models tried
  - Performance metrics (AUC, etc.)
- Conceptual risk-based premium framework

## 6. Model Interpretability (SHAP / LIME)

- Top 5–10 most influential features
- How they affect the predictions
- What this means for pricing and marketing

## 7. Recommendations for ACIS

- Which segments to target with lower premiums
- Which segments need careful pricing or stricter underwriting
- Ideas for new products / discounts based on insights

## 8. Limitations & Future Work

- Data quality issues
- Model limitations
- What you would do next with more time/data

## 9. Conclusion

Wrap up the story in a way that a non-technical stakeholder can understand.
